# Proyecto News Explorer (backend)

En este proyecto se realiza el Back-End del proyecto Full Stack News Explorer:

- la creación y autorización de usuarios en el servidor (Google Cloud),
- el manejo de errores centralizados y
- el despliegue del proyecto

## Características del proyecto

- React
- React Router
- Node.js
- MongoDB
- Express
- GCP (Global Privacy Control)
- JWT Auth
- Nodemon (Dev)
- ESLint (Dev)
